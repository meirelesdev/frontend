# Frontend

> Frontend Next.js desenvolvido como parte de um projeto full-stack, consumindo API REST com Axios e gerenciando autenticacao via cookies.

## Stack

- Next.js
- Axios

## Prerequisitos

- Node.js v14+

## Como executar

```bash
# Clone o repositorio
git clone https://github.com/meirelesdev/frontend.git
cd frontend

# Instale as dependencias
npm install

# Inicie a aplicacao
npm run dev
```
